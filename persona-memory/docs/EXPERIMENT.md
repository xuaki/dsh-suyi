# 三臂对照实验：权重式记忆 vs 纯向量 vs 证据融合层

> 这是本项目的判据。它回答一个具体问题：
> **把记忆放进「一直在训练的权重」，和放进「可追溯的证据链」，哪个更不会忘、更能纠错？**

- 实测时间：2026-10-31 02:49（Asia/Shanghai）
- 环境：Windows 11 · Python 3.12.15 · Milvus 3.0-20261030-af15c80751 · pymilvus 3.0.2
- mnemosyne 0.1.0（REST，`127.0.0.1:8765`）
- 向量器：`HashingEmbedder`（512 维 feature hashing，字符 n-gram）

---

## 一、设计

三条臂，同一份语料、同一组查询：

| 臂 | 记忆怎么存 | 能不能说出「从哪来」 | 能不能单条删 |
|---|---|---|---|
| **A. TRAINED** | 固定 **3 个原型槽**，移动平均；只留混合表征，不留逐条原文 | 否（权重里没有地址） | 否（只能整体重训） |
| **B. VECTOR** | Milvus 逐条向量，`status=active` | 否（只有文本 + 自造 id） | 是 |
| **C. FUSION** | mnemosyne 观察/候选/证据 + Milvus 向量，双写 | 是（可查到 observation 链） | 是（`invalidated` + 移出索引） |

语料：**10 条旧记忆**（猫叫团子、花生过敏、生日、咖啡不加糖、妈住杭州…），
再灌入 **10 条新记忆**（晨跑、新键盘、学做菜…）模拟「新数据一直在训练」。
查询 5 条，判据是「检索结果里是否出现原文关键词」。

> **A 臂是代理，不是真神经网络。** 但「权重里存事实」的三个性质它都具备：
> ① 无地址；② 固定容量；③ 覆盖即遗忘。这是诚实的建模，不是稻草人——
> 真实的 186M 参数连接组模型（flybrain）也证明过：结构本身没被证明有用。

---

## 二、结果

| arm | 抗遗忘 retention | 可溯源 provenance | 延迟（中位） | 单条撤销 | 纠错有效 |
|---|---|---|---|---|---|
| A_trained | **0.0**（0/5） | 0.0 | 0.25 ms | ❌ | ❌ |
| B_vector | **1.0**（5/5） | 0.0 | 3.29 ms | ✅ | ✅ |
| C_fusion | **1.0**（5/5） | **1.0** | 7.34 ms | ✅ | ✅ |

三臂遗忘明细：

- **A_trained**：5 条查询**全部召回失败**。20 条记忆压进 3 个槽，旧记忆的表征被新数据平均掉。
- **B_vector / C_fusion**：5 条全部召回成功。

---

## 三、判读

1. **权重式记忆的遗忘不是「训练不够」，是容量与覆盖的必然。**
   槽位被新数据覆盖时，旧记忆没有「位置」可以躲——它不是一个条目，是一段被平均掉的表征。
   把槽加到 20 个当然能记住，但那已经滑向「过拟合」：它能背下每一条，却不能泛化、
   也不能单条修正。

2. **可溯源不是锦上添花，是长期陪伴的底线。**
   纯向量检索记得住「三月十四号」这句话，但它不知道这是谁的生日、什么时候说的。
   融合层能回答；这是「人格连续」的前提——一个记不清来处的记忆，不能拿来支撑关系。

3. **代价是延迟：7.34 ms vs 3.29 ms。**
   多出来的一步是 mnemosyne 的权威检索（向量只能召回，不能证明）。
   毫秒级，对话场景完全可接受。

4. **权重式记忆不能单条撤销。**
   用户说「记错了」时，融合层能把那一条标 `invalidated` 并从索引移除；
   权重式只能重训，或者带着错误继续跑。这是不可接受的——长期记忆里一条错误会持续污染推理。

---

## 四、这份实验**不能**证明什么

诚实标注，避免过度解读：

- **A 臂不是真实训练网络**。它没有梯度、没有层深、没有非线性。它证明的是
  「无地址 + 固定容量 + 覆盖」这三个性质会导致什么，不是「所有神经网络记忆都不行」。
- **向量器是 feature hashing，不是真句向量**。查询刻意选了与原文有字符重叠的说法；
  换成真 embedding，三臂的召回率都会变化（但溯源差异不会变，那是结构性的）。
- **单次运行，没有多种子重复**。retention 是 0/5 和 5/5 这种强对比，不是靠边界的数字，
  所以结论对随机性不敏感；但严格来说应该补多次种子。
- **没有真实对话数据**。语料是构造的，覆盖的是「事实型记忆」，不是「情节型记忆」。

## 六、下一步值得做的实验

1. **换真句向量**（bge / text-embedding 系），看融合层在语义查询下的召回是否稳定。
2. **多种子重复**，尤其是 A 臂槽数从 3 → 10 → 20 的曲线，画出「容量-遗忘」的拐点。
3. **加入时间衰减与纠错的长期回放**：连续 1000 条观察，看 evidence 链的增长与检索质量。
4. **与 mnemosyne 自带的 FTS5 对照**：验证「向量 + 权威」混合是否真的优于纯全文。
